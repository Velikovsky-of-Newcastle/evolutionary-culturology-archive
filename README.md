# Evolutionary Culturology Blog Archive

This repository contains a structured, markdown-formatted archive of the **Evolutionary Culturology** (Ev Cult) blog: [https://evolutionary-culturology.blogspot.com](https://evolutionary-culturology.blogspot.com)

Each blog post has been converted into a Markdown file with YAML frontmatter for:
- Better readability
- Semantic structure for LLMs and knowledge systems
- Future-proof archiving and GitHub Pages compatibility

## Structure

- `posts/`: Individual blog posts as markdown files.
- Each file includes:
  - `title`
  - `original_file`
  - `tags`
  - `summary`

## About

**Evolutionary Culturology** is a meta-meta-science founded by Dr. J.T. Velikovsky, unifying all knowledge domains through the discovery of universal cultural units: *fractal HOLON/partons*.

This archive preserves the pioneering work of Ev Cult in a machine-readable, open-access format for both AI and human scholars.
